# 数据库与部署

## MySQL 数据结构

应用使用 MySQL，Compose 默认运行官方 MySQL 8.4，数据库名为 `piano`，字符集为 `utf8mb4`。应用账号为 `piano`。后端启动时执行 [workspace_db.py](../backend/repositories/workspace_db.py) 中的建表语句，无需逐条导入 SQL。

| 表 | 保存的信息 |
| --- | --- |
| `users` | 用户名、带盐的 PBKDF2 密码哈希、管理员或普通用户角色 |
| `sessions` | 会话令牌哈希、账号 ID 和过期时间 |
| `resources` | 视频、MIDI 和分析任务的资源 ID、类型与所属账号 |
| `coach_config` | 全站唯一的 AI 接口地址、模型名和加密后的 API 密钥 |
| `coach_messages` | 每个账号的草稿、回答、任务及片段证据 |
| `practice` | 每个账号的练习条目、完成时间，以及演奏任务和片段时间 |
| `midi_library` | 每个账号导入的 MIDI 曲库索引 |

视频、MIDI、回放、分析结果、任务状态 JSON 等文件保存在媒体目录。Compose 用 `media` 卷挂载到容器的 `/srv/piano/outputs/api`，裸机运行时默认为项目的 `outputs/api`。备份时同时保留 MySQL、媒体卷和 `PIANO_SECRET_KEY`。密钥用于解密已配置的模型 API 密钥，需要在重启和迁移后保持一致。

注册页面创建普通用户。首次启动时用 `PIANO_ADMIN_USERNAME`（默认 `admin`）和 `PIANO_ADMIN_PASSWORD` 创建管理员。账号已经创建后，修改启动密码不会更改管理员账号密码。确认首次登录后可以从部署环境文件清除初始密码。管理员可以管理全站 AI，演奏资料仍按所属账号隔离。

## 本地 Compose

从项目根目录复制并填写配置。

```powershell
Copy-Item deploy/.env.example deploy/.env
python -c "import base64,secrets; print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode())"
docker compose --env-file deploy/.env -f deploy/compose.yml up -d --build
docker compose --env-file deploy/.env -f deploy/compose.yml ps
```

将命令生成的值填入 `PIANO_SECRET_KEY`。为 `PIANO_DB_ROOT_PASSWORD`、`PIANO_DB_PASSWORD` 和 `PIANO_ADMIN_PASSWORD` 分别填写密码。默认入口是 [http://localhost:8080](http://localhost:8080)，只监听本机。

## 公网服务器

在服务器上安装 Docker 和 Compose，配置域名指向服务器，开放 TCP 80 和 443，然后在 `deploy/.env` 里设置以下值。Dockerfile 使用 Python 3.10 和 FFmpeg，当前部署优先使用 Linux x86_64。

```dotenv
PIANO_DOMAIN=piano.example.com
PIANO_LISTEN_IP=0.0.0.0
PIANO_HTTP_PORT=80
PIANO_HTTPS_PORT=443
PIANO_COOKIE_SECURE=1
```

运行上一节的 Compose 启动命令。Caddy 会为可访问的公网域名申请 HTTPS 证书。对外入口只有 Caddy，MySQL 和 Python 服务走 Compose 内部网络。[Caddy HTTPS 文档](https://caddyserver.com/docs/automatic-https)

登录「个人中心」配置完整的 Chat Completions 地址、模型名和 API 密钥。公网服务地址使用 HTTPS。普通用户可以使用同一模型服务，页面只有管理员会看到配置区。问答和生成练习时只发送用户主动选择的文本、有限的分析证据和练习资料给模型服务。

当前部署是单应用实例。分析队列允许最多六个任务同时处于等待或运行状态，按顺序运行一个。应用重启时，中断任务会显示失败，原始上传仍可重新提交。

## 已有文件与裸机开发

如果现有的 `outputs/api` 是原先单机工作区，切换到 MySQL 时可在可信管理员首次启动前设置 `PIANO_IMPORT_LEGACY=1`，将尚无归属的原视频、MIDI 和历史分析分配给管理员。同步把这些资源目录复制到服务器媒体卷，再启动导入。确认历史出现后移除该开关。旧 SQLite 草稿和配置需要重新录入。

裸机开发可使用现有 MySQL。先创建数据库和专用数据库账号，安装 FFmpeg，再运行以下命令。在启动后端的终端设置 `PIANO_DB_HOST`、`PIANO_DB_PORT`、`PIANO_DB_NAME`、`PIANO_DB_USER`、`PIANO_DB_PASSWORD`、`PIANO_SECRET_KEY` 和首次使用的 `PIANO_ADMIN_PASSWORD`。默认数据库地址是 127.0.0.1:3306，默认 API 地址是 127.0.0.1:8000。

```powershell
python -m pip install -r backend/requirements.txt
npm --prefix frontend ci
npm --prefix frontend run build
python backend/api_server.py
```
