# 后端接口与测试

启动方式、数据库字段和账号管理见 [数据库与部署](数据库与部署.md)。

| 功能 | 接口 |
| --- | --- |
| 账号 | `POST /api/auth/register`、`POST /api/auth/login`、`GET /api/auth/me`、`POST /api/auth/logout` |
| 上传与校准 | `POST /api/upload/video`、`POST /api/upload/midi`、`GET /api/assets/{id}/frame?time=...`、`GET /api/assets/{id}/calibration-hint?time=...` |
| 分析与回放 | `POST /api/jobs`、`GET /api/jobs`、`GET /api/jobs/{id}/result`、`GET /api/jobs/{id}/replay` |
| 教练与练习草案 | `GET /api/coach/status`、`GET/POST /api/coach`、`GET/POST /api/jobs/{id}/coach`、`POST /api/jobs/{id}/practice-plan` |
| 曲库与练习 | `GET /api/library`、`POST /api/upload/midi?library=1`、`GET/POST /api/practice`、`POST /api/practice/{id}/{complete,edit,remove}` |
| 管理员 AI 设置 | `GET/POST /api/admin/coach` |

分析模式为 `skeleton_only`、`fingering` 和 `audio`。骨架模式只需视频。指法模式还需同一次演奏的 MIDI、可见音域和标定四角。音频模式从视频音轨转录音符，可带参考 MIDI。导出文件按任务类型分别提供。

API 通过登录 Cookie 确定账号。客户端提交的任务 ID 和素材 ID 都由后端检查归属。模型密钥由服务器读取。

## 自动验证

```powershell
npm --prefix frontend run build
npm --prefix frontend run test:sites
```

HTTP 集成测试需要一个仅供测试使用的 MySQL 实例。测试会新建和清理随机命名的测试库，测试账号需能创建和删除该测试库。按实例设置 `PIANO_TEST_DB_PORT`、`PIANO_TEST_DB_USER` 和 `PIANO_TEST_DB_PASSWORD`，然后运行以下命令。

```powershell
python -m unittest discover -s tests -v
```

测试在本机自动生成 MP4 和 MIDI，通过真实 HTTP 请求验证账号权限、上传、三种分析、对齐拒识、模型请求、练习增删改和重启后的历史记录。模型端点由测试内的模拟服务提供。
